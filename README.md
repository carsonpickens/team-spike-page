# Team Spike schedule page

The public weekly schedule page that Team Spike coaches share with athletes and parents.

This repo holds **page code only, never team data**. A team's link carries a random token
(`?t=...`); the page uses it to fetch that team's week (workouts, training groups, meets) from
the Team Spike server. Coaches can hide names, replace the link, or turn the page off in the app.

Published with GitHub Pages at https://carsonpickens.github.io/team-spike-page/

The source of truth is `web/team-page/index.html` in the Team Spike app repo; copy changes here.
